## Завдання

Застосунок для роботи з електронними таблицями: введення, збереження, обробка виразів у клітинках,
зміна кількості рядків і стовпчиків. Відображення у двох режимах: **ВИРАЗ / ЗНАЧЕННЯ**.

Варіант 73 — вираз **логічний**, операції:

| № | Операції |

Також: цілі числа довільної довжини (`BigInteger`), круглі дужки, імена клітинок (`A3`, `AB12`).

## Синтаксис виразів (БНФ)

```
<вираз>        ::= <диз'юнкція> { "eqv" <диз'юнкція> }
<диз'юнкція>   ::= <кон'юнкція> { "or" <кон'юнкція> }
<кон'юнкція>   ::= <заперечення> { "and" <заперечення> }
<заперечення>  ::= "not" <заперечення> | <порівняння>
<порівняння>   ::= <степінь> { ( "=" | "<" | ">" ) <степінь> }
<степінь>      ::= <первинний> [ "^" <степінь> ]
<первинний>    ::= <число> | <клітинка> | "(" <вираз> ")"
<число>        ::= <цифра> { <цифра> }
<клітинка>     ::= <буква> { <буква> } <ненульова цифра> { <цифра> }
<буква>        ::= "A" | ... | "Z" | "a" | ... | "z"
<цифра>        ::= "0" | ... | "9"
```

Пріоритет (від найвищого): `( )` → `^` → `= < >` → `not` → `and` → `or` → `eqv`.
`^` — правоасоціативна (`2^3^2 = 2^9 = 512`), решта бінарних — лівоасоціативні.
Ключові слова й імена клітинок нечутливі до регістру. Пропуски можна ставити як завгодно.

**Логічні значення:** істина = `1`, хибність = `0`; будь-яке ненульове число вважається істиною
(як у мові C). Порожня клітинка має значення `0`.

Приклади:

| Вираз | Значення |
|-------|----------|
| `2^10 > 1000` | 1 |
| `not (3 = 3)` | 0 |
| `1 or 0 and 0` | 1 (`and` виконується першою) |
| `(A1 > 5) eqv (B1 > 5)` | 1, якщо обидві умови однакові |

### Два етапи обробки

1. **Синтаксична перевірка** — `Lexer` розбиває рядок на лексеми, `Parser` (рекурсивний спуск за БНФ)
   будує дерево виразу. Помилка → `ParseException` з **позицією** символу.
2. **Обчислення** — метод `Evaluate` вузлів дерева (`NumberNode`, `CellNode`, `NotNode`, `BinaryNode`).
   Помилки обчислення (циклічне посилання, неіснуюча клітинка, завеликий степінь) → `CalculationException`.

У клітинці з помилкою показується `#ПОМИЛКА`, а повний опис — у рядку стану при виборі клітинки.
Циклічні посилання (`A1 = B1`, `B1 = A1`) знаходяться за допомогою стану клітинки «обчислюється».

## Формат файлу

Власний формат на основі JSON (зберігаються розмір і непорожні вирази):

```json
{
  "Rows": 10,
  "Columns": 6,
  "Cells": {
    "A1": "2^10",
    "B1": "A1 > 1000 and not 0"
  }
}
```

На комп'ютері таблицю можна зберегти в будь-яку папку і відкрити з будь-якої папки — через стандартні
вікна Windows «Зберегти як» / «Відкрити». На Google Drive таблиці зберігаються в корені диска.
